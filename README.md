# Probability Project

Group project for **ST2004 Applied Probability**.

**Working question:** can early-spring weather data from Met Éireann (grass minimum temperature, soil temperature and dew point) give Irish farmers a reliable early warning to delay planting and avoid damaging ground frost? Does the answer depend on where the farm is?
